# Adding New Examples to the Gallery

## Quick Reference

To add a new example (notebook, reproduced paper, or rust), follow these 3 steps:

### Step 1: Create the Stub File

Create a new Python file in the appropriate examples directory:

- **Notebook example**: `docs/source/examples/notebooks/plot_my_example.py`
- **Paper reproduction**: `docs/source/examples/reproduced_papers/plot_my_paper.py`
- **Rust example**: `docs/source/examples/rust/plot_my_rust.py`

### Step 2: Write the Minimal Docstring

The stub file should contain:
- A title (reStructuredText heading)
- An image reference
- A `:Target:` link to a docs page or external URL
- A `sphinx_gallery_thumbnail_path` comment

Template:

```python
"""
.. image:: /_static/examples/my_thumbnail.png
   :alt: My Example
   :width: 200px
   :align: center

My Example Title
================

:Target: :doc:`/notebooks/FirstQuantumLayers`
"""
# sphinx_gallery_thumbnail_path = "/_static/examples/my_thumbnail.png"
```

For external links:

```rst
:Target: `Open source <https://...>`_
```

### Step 3: Add Your Thumbnail and Rebuild

Place your thumbnail in:

`docs/source/_static/examples/my_thumbnail.png`

Then rebuild docs:

```bash
cd docs
make html
```

## Important: What Is Generated vs. Manual

- `docs/source/auto_examples/*` is generated by `sphinx-gallery` from `docs/source/examples/*`.
- Do not manually maintain cards in `docs/source/auto_examples/*/index.rst`.
- The section landing pages in `docs/source/examples/notebooks/index.rst`, `docs/source/examples/reproduced_papers/index.rst`, and `docs/source/examples/rust/index.rst` simply point to generated gallery pages.
- The top-level examples hub `docs/source/examples/index.rst` is manually curated and may be updated if you want to feature new content there.

## Step-by-Step Process (Notebook Example)

1. Create the notebook file in `docs/source/examples/notebooks/`.
Example: `docs/source/examples/notebooks/FromSimpleToBuilder.ipynb`

2. Create a gallery stub in `docs/source/examples/notebooks/` with a `plot_` prefix.
Example: `docs/source/examples/notebooks/plot_from_simple_to_builder.py`

3. Add the stub content:
- a title
- an image (`.. image:: /_static/examples/...`)
- a `:Target:` link (internal `:doc:` or external URL)
- `# sphinx_gallery_thumbnail_path = "..."`

4. Add the thumbnail image to `docs/source/_static/examples/`.
Example: `docs/source/_static/examples/SimpleToBuilder.svg`

5. Update the top-level manual hub card in `docs/source/examples/index.rst` if you want the new example featured on `/examples/`.
For direct notebook opening, use:
`<a href="notebooks/FromSimpleToBuilder.html" class="gallery-card">`

6. Rebuild docs:

```bash
cd docs
make clean
make html
```

7. Validate output in browser:
- `/examples/` shows the new card if added in `examples/index.rst`
- `/examples/notebooks/FromSimpleToBuilder.html` opens the notebook page
- `/auto_examples/notebooks/plot_from_simple_to_builder.html` opens the gallery-generated page

## Example: Add a Notebook Gallery Card

### 1. Create stub file

`docs/source/examples/notebooks/plot_iris_classification.py`

```python
"""
.. image:: /_static/examples/iris_classification.png
   :alt: Iris Classification with Quantum Layers
   :width: 200px
   :align: center

Iris Classification with Quantum Layers
=======================================

:Target: :doc:`/notebooks/iris_classification`
"""
# sphinx_gallery_thumbnail_path = "/_static/examples/iris_classification.png"
```

### 2. Add thumbnail

Place `iris_classification.png` in `docs/source/_static/examples/`.

### 3. Rebuild docs and verify

- Open `docs/source/auto_examples/notebooks/index.rst` in built output to check the new card appears.
- Open `docs/source/auto_examples/notebooks/plot_iris_classification.html` in built output to check the target link.

## Notes

- Sphinx-Gallery converts each stub file into a gallery item and example page.
- You can use `.png` or `.svg` for thumbnails.
- Keep titles short and thumbnails clear.
